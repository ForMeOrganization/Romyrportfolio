# Romyr's Portfolio 

Live app: http://portfolioromyr.io/

## Overview

This is a portfolio built with React, TypeScript, Vite, Tailwind CSS, and shadcn-style UI utilities.

SHOWCASING MY

- Recent projects 
- Recent achievements
- Certifications and course completions

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Lucide React
